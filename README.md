## Description
This is an example of LLM implementation using LiteRT on Android. 

## Getting Started
1. Add the dependency "com.google.ai.edge.litert:${latest-version}" to your Gradle.
2. Download SmolLM model with .tflite format from this [link](https://huggingface.co/litert-community/SmolLM-135M-Instruct) or this [link](https://huggingface.co/HuggingFaceTB/SmolLM-135M-Instruct) if you want to convert to .tflite format manually
3. Place the model in the assets folder
4. Build and run.

## Model
SmolLM
